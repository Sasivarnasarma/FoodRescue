# 14 — Glossary

| Term | Meaning |
|---|---|
| Donor or provider | Approved business that publishes a free surplus-food listing |
| Recipient | Approved organization that requests the entire listing |
| Request | Recipient's proposed pickup and declaration that it can meet the listing's storage requirements |
| Assignment | Donor approval of one request for the whole listing |
| Smart matching | Deadline prioritization and comparison of eligible recipient requests by pickup feasibility |
| Storage compatibility | Recipient's declaration that it can meet the donor's requirements for ambient, chilled or frozen food |
| Pickup reference | Opaque listing ID in a QR or entered manually |
| Handover confirmation | Assigned recipient's signed-in acknowledgement required for donor completion |
| Spark | Firebase plan used for the university MVP without a linked billing account |
| Firestore listener | Authorized stream of document changes used for live updates across devices |
