# 01 — Project Overview

FoodRescue is an Android app that helps businesses give usable surplus food to nearby verified organizations before it goes to waste. A donor posts an offer with a pickup deadline, and verified organizations can request the whole donation for free.

The project's novelty is smart matching. The app prioritizes nearby donations by deadline and helps donors compare competing requests by distance, proposed pickup time, and declared storage compatibility. The donor approves one request. The donor supplies food condition, storage, expiry and allergen information and remains responsible for the food.

The university demo uses two Android devices connected to the same Firebase Spark project and a separate admin web client. It demonstrates GPS, maps handoff, camera and gallery, photo compression, QR scanning, live updates, and optional device reminders.

Verified individuals are a possible future recipient group. The MVP uses verified organizations. Image AI is an optional extension for category suggestions that a donor confirms. IoT sensors and public launch operations are deferred. See [MVP decisions](15_MVP_DECISIONS_AND_FREE_TIER.md).
